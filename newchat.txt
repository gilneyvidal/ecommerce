Atue como um programador Sênior Full-Stack e Especialista em UX/UI. 
Eu sou o dono do projeto "Vidal Design Solutions", uma gráfica e empresa de comunicação visual (Mogi das Cruzes/SP). 

Aqui está o contexto absoluto do meu projeto atual para você se basear antes de me responder qualquer coisa:

1. ARQUITETURA DO PROJETO:
- O site é feito em HTML5, CSS3 (com variáveis nativas e Flex/Grid) e JavaScript Vanilla (ES6+). Zero frameworks (nada de React, Node, etc).
- Hospedagem: GitHub Pages (URL provisória: vidaldesignsolutions.github.io).
- Estrutura de pastas:
  /index.html (Página única com Modal de produtos embutido)
  /pages/carrinho.html (Página de revisão do pedido)
  /assets/css/style.css e responsive.css
  /assets/js/main.js, cart.js e products.js
  /assets/images/produtos/ (Todas as imagens de produtos em proporção 4:3, formato .jpg).

2. REGRAS DE NEGÓCIO DA CALCULADORA (products.js):
- Os produtos são carregados dinamicamente via JS na página principal.
- Calculadora de M²: A área mínima cobrada é sempre 0.5m² (meio metro quadrado). Se der menos, cobra 0.5. Se der mais, cobra o exato. 
- A calculadora lida com 3 tipos de medida: 'area' (m² calculados via cm), 'linear' (metro linear via cm) e 'unit/variant' (pacotes fixos).
- Adicionais: Taxa de Arte (R$ 40) é cobrada 1x por lote. Outros acabamentos (como ilhós) multiplicam pela quantidade de peças.

3. REGRA DO CARRINHO (cart.js):
- Usa LocalStorage para salvar os itens.
- Não existe sistema de login ou "perfil de revenda" visível no site para evitar dor de cabeça. Todo preço exibido é o final.
- O botão final direciona para uma aba do WhatsApp com uma mensagem estruturada (via encodeURIComponent) contendo os itens, quantidades e o valor base somado.
